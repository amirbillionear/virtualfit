# VirtualFit: پرو مجازی فضایی (Spatial Try-On)

یک تجربه پرو مجازی لباس به سبک **visionOS** با رابط کاربری شیشه‌ای (Frosted Glass)، چرخ‌والمس سه‌بعدی لباس‌ها، اسکن هولوگرافیک روی مانکن و تغییر رنگ هوشمند پارچه لباس در لحظه.

## ✨ ویژگی‌ها
- **چرخ‌فلک سه‌بعدی لباس‌ها (3D Garment Arc):** قابلیت چرخش با ماوس (Drag & Flick)، اسکرول، کلیدهای جهت‌نما و لمس موبایل.
- **اسکن هولوگرافیک لباس روی مانکن:** افکت خط اسکن نوری هنگام تعویض لباس یا تغییر رنگ.
- **تغییر رنگ هوشمند لباس (Real-time Recoloring):** تغییر دقیق رنگ لباس روی تن مانکن، کارت‌های سه‌بعدی و تصویر بندانگشتی با حفظ سایه‌روشن‌ها و بافت پارچه.
- **بومی‌سازی کامل فارسی:** مجهز به فونت فارسی `YekanBakhFaNum` و قیمت‌گذاری به تومان.
- **بهینه‌شده برای GitHub Pages:** مسیرهای کاملاً نسبی (`./`) برای اجرا بدون نیاز به سرور بک‌اند، هم به صورت مستقیم روی شاخه اصلی (`main`) و هم از طریق `GitHub Actions`.

## 🚀 نحوه انتشار روی GitHub Pages
1. از نوار بالای محیط **Google AI Studio** روی آیکون **GitHub (Save to GitHub)** کلیک کنید تا پروژه مستقیم در اکانت گیت‌هاب شما ذخیره شود.
2. وارد مخزن (Repository) خود در گیت‌هاب شوید و به بخش **Settings > Pages** بروید.
3. در قسمت **Build and deployment**، گزینه **Source** را روی **GitHub Actions** (یا **Deploy from a branch** روی شاخه `main` / پوشه `/root`) قرار دهید.
4. لینک سایت شما در آدرس `https://<username>.github.io/<repo-name>/` فعال خواهد شد.
